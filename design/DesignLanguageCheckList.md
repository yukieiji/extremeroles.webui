
# デザイン定義チェックリスト

## 1. カラーシステム（色彩設計）

- [x] **基本テキストカラー（3種）**
    - **Primary Text Color** : `#0B1728`
        - 設定項目名など、最も重要なテキスト。
    - **Secondary Text Color** : `#52525B`
        - 設定の補足説明、注釈、デフォルト値。
    - **Disabled Text Color / Tertiary Text Color** : `#A1A1AA`
        - 見づらかった#71717Aにするかもしれない
        - 無効な項目やプレースホルダー。
- [x] **役職カラーパレット（Role Colors）**
    - これはドメインカラー
        - 各役職のカラー: 役職のアコーディオンヘッダー（リニアーグラディアントの右）とアコーディオンの境界線（ヘッダーとコンテンツの境界には使用しない）
    - タブのカラー: タブ選択中のインジケーターとタブ選択中の枠の色
- [x] **プライマリーアクション色**
    - **通常時 (Primary)**: `#9CE1FD`
    - **ホバー時 (Hover)**: `#9CE1FD` (不透明度 80%)
    - **アクティブ時 (Active)**: `#7DD3FC`
    - 「保存」「追加」など、ユーザーが次に行うべき主要なアクションを示す色。
    - 必ずPrimary Text Colorを組み合わせる


- [x] **セマンティックカラー（状態色）**
    - **エラー色**: `#F43F5E` (1300項目の中からエラー箇所を見つけ出すために必須)
    - **警告色**: `#D97706`
    - **成功色**: `#16A34A`
    - **情報色**: `#818CF8`


- [x] **ニュートラルカラー**
    - **Level 1 (最背面背景)**: `#F4F4F5`
        - アプリ全体のメイン背景色、最背面のレイヤーに使用。
    - **Level 2 (標準的な枠線)**: `#D0D0D6`
        - 外枠のボーダーと背景との枠線などの意味が異なるコンポーネントを区切る強い枠線。
    - **Level 3 (区切り線・弱い枠線)**: `#E4E4E7`
        - 同じ要素同士を分ける区切り線（Separator）や、非常に弱い枠線に使用。
    - **Level 4 (コンテンツ面・カード背景)**: `#FFFFFF`
        - メインコンポーネントの背景。
    - **Level 5 (最前面・入力欄)**: `#FFFFFF`
        - 最前面、ユーザーが操作する場所（入力欄）。Level4と組み合わせる場合は必ずLevel2の枠線及びシャドウを入れる
- [x] **検索ハイライト色**
    - **ハイライト枠線 (Ring)**: `#3b82f6`
    - **自動消去時間**: 2000ミリ秒
    - 検索ワードに一致した箇所を目立たせる色。


## 2. タイポグラフィ（文字設計）

- [x] **フォントサイズ・ウェイト階層**
    - **サイドバー** : 標準サイズ (Base) / セミボールド (Semibold)
    - **タブ** : 標準サイズ (Base) / ミディアム (Medium)
    - **ラベル** : 標準サイズ (Base) / ノーマル (Normal)
    - **子ラベル** : 小サイズ (Small) / ミディアム (Medium)
    - **小（注釈など）** : 極小サイズ (X-Small) / ノーマル (Normal)
- [x] **行間（Line Height）の定義**
    - 1.5倍
        - 情報密度が高いため、詰まりすぎず、かつ離れすぎない最適な行間を設定。
- [x] **データ用フォント（等幅）**
    - 等幅フォント (Monospace)
        - IDや数値、設定値など、正確な読み取りが必要な箇所への適用。

## 3. グリッドシステム

- [x] **間隔・余白定義 (4pxベース設計)**
    - **Small (超小単位)**: 4px
        - 非常に密接な要素間の距離に使用。
    - **Base (標準小単位)**: 8px
        - 標準単位。カードのパディングや、一般的な項目間の距離に使用します。
    - **Large (中間単位)**: 12px
        - 中間単位。意味が大きく異なるなど大きな余白を作りたい時
    - **X-Large (標準大単位)**: 16px
        - 最大単位。基本的に使用しない
