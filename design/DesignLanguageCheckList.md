# デザイン定義チェックリスト

## 1. カラーシステム（色彩設計）
- [ ] : **基本テキストカラー（3種）**
    - **Primary Text Color** :
      - 設定項目名など、最も重要なテキスト。
    - **Secondary Text Color** : 
      - 設定の補足説明、注釈、デフォルト値。
    - **Disabled Text Color/Tertiary Text Color** : 
      - 無効な項目やプレースホルダー。
- [x] :  **役職カラーパレット（Role Colors）**
    - これはドメインカラー 
        - 各役職のカラー: 役職のアコーディオンヘッダー(リニアーグラディアントの右)とアコーディオンの境界線(ヘッダーとコンテンツの境界には使用しない)
        - タブのカラー: タブ選択中のインジケーターとタブ選択中の枠の色
- [ ] :  **プライマリーアクション色**: 
    - 「保存」「追加」など、ユーザーが次に行うべき主要なアクションを示す色。
- [ ] :  **セマンティックカラー（状態色）**: 
    -  エラー色
    -  警告色
    -  成功色
    -  情報色
       - 1300項目の中からエラー箇所を見つけ出すために必須。
- [x] : **ニュートラルカラー**
    - 背景
    - 枠線
    - カードの区切り
      - 情報を「階層化」するために5〜7段階の濃度を定義。
- [ ] : **検索ハイライト色**
    -  検索ワードに一致した箇所を目立たせる色。
