# カード内のフル幅ボタンのレイアウト

## 概要
カード（Card）コンポーネント内で、特にグリッド（Grid）レイアウトを使用しているヘッダー等にボタンを配置する場合、ボタンを横幅いっぱいに広げるには `w-full` だけでなく `col-span-full` の指定が有効です。

## 実装例
Shadcn/UIベースの `CardHeader` など、内部で `grid` が使用されているコンポーネント内にボタンを配置する場合：

```tsx
<Button className="w-full col-span-full">
  ボタンテキスト
</Button>
```

## 理由
- `w-full`: ボタン自体の幅を親要素（グリッドアイテム）の100%に設定します。
- `col-span-full`: グリッドレイアウトにおいて、ボタンがすべてのカラムを占有するように設定します。これにより、他の要素（例：AssignNumの調整ボタンなど）と同じ行に並んでしまうのを防ぎ、独立した行としてカードの端から端まで広げることができます。
