# スライダー入力欄の挙動修正と状態管理

## 課題
OptionSingleSlider などのコンポーネントで、入力欄をクリアして新しい値を入力しようとすると、クリアした瞬間に NaN になり、元の値に戻ったり入力を受け付けなくなったりする不具合があった。

## 解決策
1. **グローバルストアでの管理**:
   AGENTS.md のルールに従い、`useState` を使用せず Zustand ストアで「入力中の文字列」を保持するようにした。
2. **確定タイミングの変更**:
   入力イベントごと (`onChange`) に親の状態を更新するのではなく、フォーカスが外れた際 (`onBlur`) または Enter キーが押された際に値を確定させるようにした。これにより、入力途中の不完全な状態（空文字やマイナス記号のみなど）を許容できるようになった。
3. **同期処理**:
   スライダー操作などでプロップスの値が変わった場合は、`useEffect` を用いてストア内の値をクリアし、最新の値が表示されるように同期した。

## コードスタイル
- React のフックは名前付きインポート (`import { useEffect } from "react"`) を使用する。
- Biome のリンタールールに従い、`useState` は原則禁止とする。
