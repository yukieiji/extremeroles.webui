# PRテンプレートの導入

## 概要
GitHubでのプルリクエスト作成時に、必要な情報を漏れなく記載できるようにテンプレートを導入しました。

## 設置場所
`.github/pull_request_template.md`

## テンプレートの内容
- **変更内容**: 変更の概要
- **スクリーンショット**: UIの変更がある場合に添付
- **関連Issue**: 関連するIssueへのリンク
- **チェックリスト**:
    - リントチェック (`pnpm run check`)
    - テストパス (`pnpm run test`)
    - e2eパス (`pnpm run e2e`)
    - 変更内容に対するテスト追加
    - 変更内容に対するe2eテスト追加

## 使い方
GitHub上でPRを作成すると、自動的にこのテンプレートの内容が本文に挿入されます。各項目を埋めてPRを作成してください。
