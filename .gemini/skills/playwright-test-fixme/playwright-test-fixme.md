# Playwrightにおけるテストの一時的な無効化 (test.fixme)

## 概要
Playwrightでテストが失敗することが分かっているが、コードの修正が完了するまでテストをスキップしたい場合、単にコメントアウトするのではなく `test.fixme()` を使用するのがベストプラクティスです。

## 使用方法
テスト関数の内部で `test.fixme()` を呼び出すことで、そのテストを「修正が必要なもの」としてマークし、実行をスキップできます。

```typescript
test("未実装の機能のテスト", async ({ page }) => {
  // 特定の条件でスキップする場合
  test.fixme(true, "ロジックが未実装のため一時的に無効化");

  // 以降のコードは実行されません
  await expect(page.locator(".some-element")).toBeVisible();
});
```

## 利点
- **可読性**: テストコードがコメントアウトされずに残るため、将来何をテストすべきかが明確です。
- **レポーティング**: テスト結果に「Skipped」または「Fixme」として表示され、放置されるのを防ぎます。
- **保守性**: コメントアウトによる「死んだコード」の蓄積を防ぎます。
